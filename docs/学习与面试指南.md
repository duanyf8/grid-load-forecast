# 学习与面试指南

> 适合：Python 零基础、每天能投入 3–4 小时、目标国家电网/南方电网计算机类或数据类岗位。  
> 目标：3 天左右把项目跑通、讲清楚，并写进简历。

---

## 0. 先记住三句话

1. **你不需要从零手写所有代码。**  
   先跑通，再按顺序读懂，最后改一个参数做对比。面试官更关心你能不能解释，而不是你背了多少语法。

2. **项目必须能“自圆其说”。**  
   数据是模拟的、模型是随机森林、指标是 4% 左右，这些都要能解释。不要编“国网真实数据”。

3. **一个讲透的项目，胜过三个半成品。**  
   把这个项目讲 3 分钟，比在简历上堆五个“熟悉/了解”更有用。

## 3. 10 个必须能回答的面试问题

### Q1：这个项目解决什么问题？

> 配电台区需要提前掌握负荷，避免重过载；同时需要从负荷数据里发现异常用电。  
> 我做了一个从数据生成、清洗、特征工程、负荷预测到异常筛查和可视化的完整系统，重点是走通业务闭环。

### Q2：数据是哪来的？

> 模拟数据。真实台区数据涉及用户隐私，学生一般拿不到，所以我按 96 点负荷规律生成了 5 个台区、60 天的数据，并注入了缺失值、重复值和异常点。  
> 项目重点验证方法流程，不涉及真实用户信息。如果有真实数据，模型和特征可以复用。

### Q3：为什么用随机森林，不用 LSTM？

> 数据量只有约 2.8 万条，LSTM 容易过拟合，训练和调参成本也高；随机森林在表格特征上表现稳定、可解释、训练快，适合快速做出 MVP。  
> 如果后续有更长历史和更多特征，可以再对比 LightGBM、Prophet 或 LSTM。

### Q4：什么是数据泄漏？你怎么避免？

> 数据泄漏就是训练时用到了预测时点之后的信息，导致测试指标虚高。  
> 我按时间切分，前 50 天训练、后 10 天测试；滞后特征只取预测时点之前的数据；没有随机打乱时间序列。

### Q5：MAPE 4.01% 是什么水平？

> MAPE 是平均绝对百分比误差，4.01% 表示预测值平均偏离实际值约 4%。  
> 在这个模拟数据集上，它比“昨天同时刻”的基线 7.11% 低了约 3.1 个百分点。  
> 真实台区受天气、节假日、用户行为影响，误差通常会更高，不能直接把这个数字套到真实场景。

### Q6：为什么每个台区单独建模？

> 居民、工业、商业台区的负荷规律差异很大，比如工业台区周末负荷可能下降，商业台区周末反而上升。  
> 每个台区单独建模，模型能学到自己的日周期和周周期；代价是台区多了以后模型数量会增加，可以再考虑全局模型 + 台区特征。

### Q7：异常检测怎么做的？

> 对每个台区、每个时刻，取过去 7 天同一时刻负荷的中位数作为期望值；  
> 计算实际值和期望值的残差，用 MAD 估计稳健标准差，算稳健 Z 分数；  
> 同时满足 `|Z| >= 4.5` 和偏差绝对值 >= 20% 才标记为异常。  
> 这样比单纯用 3σ 更不容易被极端值影响。

### Q8：精确率 79.8%、召回率 100% 说明什么？

> 召回率 100% 说明注入的异常基本都被抓到了；精确率 79.8% 说明告警里还有约 20% 是误报。  
> 这是模拟数据，异常注入得比较明显，所以召回率偏高。真实场景会更复杂，异常检测只能作为筛查，最后要人工复核。  
> 如果业务更怕漏报，就降低阈值；如果更怕误报，就提高阈值。

### Q9：项目最大的难点是什么？

> 一是特征工程，要让模型只能使用历史信息；二是把模型输出变成稳定的 API 和看板；三是异常检测阈值要在误报和漏报之间权衡。  
> 最大的收获是完整走通了“数据—模型—服务—可视化”的链路，而不是只写了一个训练脚本。

### Q10：如果上线，怎么改进？

> 接实时负荷和气象数据；换 MySQL/PostgreSQL；加节假日、电价、用户类型特征；  
> 对比 LightGBM/Prophet；加定时任务做滚动预测和模型监控；加登录权限、告警推送和人工复核流程。

### 附加问题：你负责哪部分？

> 这是个人项目，我独立完成数据生成、特征工程、模型训练、API、前端看板和文档。  
> 开发过程中用 AI 辅助查文档和生成部分模板代码，但核心逻辑、指标和每一段代码我都自己跑过、改过，可以现场讲。

## 6. 常见问题

### Python 不是内部或外部命令

安装 Python 时没有勾选 “Add Python to PATH”。  
重新安装，勾选该选项，或者手动把 Python 安装目录和 `Scripts` 目录加入 PATH。

### pip 安装很慢

可以用国内镜像：

```bat
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 5000 端口被占用

```bat
netstat -ano | findstr :5000
taskkill /PID <PID> /F
```

或者把 `app.py` 最后的 `port=5000` 改成 `5001`。

### 页面图表不显示

ECharts 默认从 CDN 加载，需要联网。  
如果网络不稳定，可以下载 `echarts.min.js` 放到 `static/vendor/`，然后把 `templates/base.html` 里的 CDN 地址改成：

```html
<script src="{{ url_for('static', filename='vendor/echarts.min.js') }}"></script>
```

### 提示数据库不存在

按顺序运行：

```bat
python data\generate_data.py
python scripts\init_db.py
```

### 训练时报 PermissionError

项目里已经设置 `n_jobs=1`，避免 Windows 沙箱/多进程权限问题。  
如果你改成了 `n_jobs=-1`，改回 `1`。

### 双击 `start.bat` 出现乱码或“'1' 不是内部命令”

旧版 `start.bat` 使用了 UTF-8 编码 + LF 换行，Windows `cmd.exe` 在解析中文时可能错位，出现：

```text
'1' 不是内部或外部命令
'lse' 不是内部或外部命令
'orlevel' 不是内部或外部命令
```

这不是 Python 代码的问题，也不是电脑中毒。  
现在 `start.bat` 已经改成 **纯英文提示 + Windows CRLF 换行**，重新双击即可。

如果还开着旧窗口，先在窗口里按 `Ctrl + C` 停止服务，再双击新的 `start.bat`。  
控制台显示英文是正常的，网页、代码注释和文档仍然是中文。

## 8. 最后一句

电网校招面试官通常不是算法专家，他们更关心：

- 你是不是真的做过；
- 你能不能把业务、数据、模型、系统讲清楚；
- 你遇到问题怎么解决；
- 你愿不愿意学、能不能稳定去基层。

所以，**不要追求项目多，追求一个能讲透。**  
把这份指南里的 10 个问题练熟，比再做一个新项目更有用。
